# The NPC Detector

The NPC Detector turns mundane answers into an absurdly specific fictional character dossier.

## Run locally

Open `index.html` in any modern browser. The app is dependency-free and stores no personal data.

## Included

- Ten-question, one-at-a-time experience
- Progress indicator and playful evidence observations
- Four NPC profiles selected from the user's answer pattern
- Generated dossier with role, alignment, threat level, behavioral summary, dialogue loops, quests, inventory, abilities, lore, rumors, stats, and secret ending
- Responsive layout for mobile and desktop
- Copy dossier and restart controls
